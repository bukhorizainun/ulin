# Ulin

Arcade game retro di browser. Hayu ulin bareng: https://bukhorizainun.github.io/ulin/

Semua game adalah homebrew NES dengan lisensi terbuka. Kodenya diambil dari rilis resmi pembuatnya, tanpa diubah:

| Game | Pembuat | Lisensi | Sumber |
|---|---|---|---|
| Nova the Squirrel | NovaSquirrel | Kode GPL-3.0, aset CC BY-NC-SA 4.0 | https://github.com/NovaSquirrel/NovaTheSquirrel/tree/v1.0.6a |
| Minekart Madness | Matt Hughson | MIT | https://github.com/mhughson/mbh-cart/tree/v1.0 |
| Thwaite | Damian Yerrick | GPL-3.0 | https://github.com/pinobatch/thwaite-nes/tree/v0.04 |
| Concentration Room | Damian Yerrick | GPL-3.0 | https://github.com/pinobatch/croom-nes/tree/v0.02a |

Emulator: [jsnes](https://github.com/bfirshman/jsnes) 1.2.1, Apache-2.0 (`vendor/jsnes-LICENSE.txt`).

Ulin tidak memasang iklan dan tidak menjual apa pun. Aset Nova the Squirrel berlisensi non-komersial, jadi game itu harus dilepas kalau situs ini pernah dimonetisasi.
